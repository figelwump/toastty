Manual setup

Prefer to set things up yourself, or hit issues with the prompt? Run each step from any terminal.

Shell integration
Enable live titles, restored pane history, and manually started agent tracking—including inside tmux and zmx.
"$TOASTTY_CLI_PATH" setup install-shell-integration --dry-run

After applying, open a new Toastty pane to load the integration; existing nested shells and tmux or zmx sessions may need to restart first.

Codex status hooks
Codex may ask you to trust the hook once. Claude Code and Cursor hooks are automatic for Toastty launches.
"$TOASTTY_CLI_PATH" setup install-hooks --agent codex --dry-run
Toastty skills
Review the built-in skills and accepted user skills from ~/.toastty/skills. New managed launches receive the current set automatically.
"$TOASTTY_CLI_PATH" setup skills list
