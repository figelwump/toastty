Design-doc states demonstrated

  • Awaiting input (amber) — compose enabled; approve/deny on the pending push. Note: v1 ships approvals read-only ("respond on desktop") until providers expose a semantic approval channel; this shows the target interaction.
  • Working (green) — compose locked: "input opens at the next prompt."
  • Local draft — open Smoke test triage: the desktop has an unsent draft, so remote input is paused (the epoch rule).
  • Offline — open Log spelunking: conversation readable, resume happens on the desktop.
