Building blocks

Everything on screen is something your agent can use.

Toastty is a terminal multiplexer at its core, so it works with Claude Code, Codex, Cursor, Grok Build, OpenCode, Pi, or any CLI you run. What it adds is a set of pieces your agents can arrange for you.

PR #128
1 2 2 3 4 6
5toastty action run workspace.create · panel.create.local-document · workspace.set-annotation
  1. Workspaces and tasksOne workspace per project, in the sidebar. Each task gets a task space under its project, and the Tasks view lists them all.
  2. Tabs and splitsAny terminal layout, with any agent or command in each pane. Layouts persist across restarts.
  3. Right panelScratchpad pages, local files, and a browser beside the terminal: plans, mockups, handoffs, previews.
  4. Status and chipsLive agent status and notifications, plus links like PR #128 or ENG-412 pinned to a workspace.
  5. The toastty CLIEvery piece above, callable from a skill or a script. Skills in ~/.toastty/skills reach every supported agent you launch.
  6. The coordinatorOne long-lived agent that uses every piece above to follow your tasks. It creates them from your requests, answers what your policy settles, and passes the rest to you.
Workflows

Put the pieces together however you work.

A workflow is a short skill file that tells your agent which pieces to use and when. Tasks and the coordinator are built in. For anything else you do the same way each time, describe how you work and let your agent write one.

Coordinated tasks

"fix the login redirect"Built in

Tell the coordinator what you need, and it creates the task. The task's agent works in its own task space and worktree while the coordinator follows CI, questions and review. Press Merge, and Toastty merges the PR and removes the worktree.

git · GitHub

Issue to PR

"start ENG-412"

Reads the issue, names a workspace after it with a chip linking back, drafts the plan in a Scratchpad, and links the PR on the issue when it's up.

Linear · GitHub Issues

Review queue

"review my PRs"

Opens a task space per requested review with the diff in the browser, writes notes into a Scratchpad, and notifies you as each one is ready.

GitHub

Spec to tasks

"build from this spec"

Opens the spec beside the terminal and hands it to the coordinator, which splits it into tasks, starts each one, and keeps a progress page up to date.

Google Docs · Notion · Markdown

Crash to fix

"fix this crash"

Reproduces the report in a worktree with the dev server in a split the agent can read, then shows before and after screenshots.

Sentry · logs

Second opinion

"ask another model"

Runs two agents side by side on the same question and compares their answers in a Scratchpad.

Any two CLI agents

Tasks and the coordinator are built into Toastty; see Tasks. The others are ideas to describe to your agent. Issue trackers and documents are reached through your agent's own tools, such as MCP servers or gh. Toastty provides the workspace around them.

Sidebar

See what needs you next.

Every project is a card in the sidebar. Sessions and tasks report live status, and the rows that want you are tinted: green when ready, amber when waiting for approval, red on an error.

  • Needs you firstEach project card sorts its sessions and tasks into Needs you, Ready to review, Running and Idle. A task that asks you something waits under Needs you as “Asks: which staging region?” until you answer.
  • Switch to Needs youSee only the questions, approvals and pull requests that wait on you, from every project, one line each.
  • Jump to what's next⌘⇧A cycles through unread, approval, and active sessions.
  • Mark for later⌘⇧L flags a session; the flag clears when it moves forward.
  • OSC 7501 supportPrograms that report OSC 7501 status appear in the sidebar with progress and approval, input, or login labels.You can also watch any command with ⌘⇧M and get notified when it exits.
  • NotificationsNative macOS notifications and unread badges, so you can look away.

Rich status for Claude Code, Codex, Cursor, Grok Build, OpenCode, MiMo Code, and Pi. Any process or agent CLI that supports OSC 7501 will provide basic status updates as well.

Tasks and Merge

⇧⌘T lists every task by what it needs from you. Merge is your sign-off: the agent checks review threads and CI, then Toastty merges that commit and cleans up the worktree.

Without the coordinator, quick entry creates the task directly. Agents and scripts make tasks with toastty task create, and so does Toastty Mobile. The coordinator's chat and dock need macOS 15. Tasks covers the details.

Toastty Mobile TestFlight beta

Check on your agents from your phone.

The same sidebar and the same coordinator, on your iPhone. See what needs you, answer the questions your agents ask, and hand the coordinator the next task, all over your private tailnet.

  • What needs you, liveNeeds you lists the questions, approvals and pull requests from every project; All shows every session and task, grouped as on the Mac.
  • Answer your agents' questionsWhen an agent asks you to choose, pick an option or type a custom answer. It lands in the terminal on your Mac as if you were there.
  • The coordinator, in your pocketThe Coordinator tab is the same chat as the Mac's dock: ask for a task, read why one is ready, and say "merge it". The Tasks tab lists every task, and a task's own conversation has a Merge button.
  • Reply from anywhereSend the next prompt with photos and files attached. While the agent works, queue a follow-up for the next turn, steer a Codex or Claude Code turn, or stop it.
  • Scratchpads and filesOpen the pages, documents, and previews your agents published, and tap a PR chip to read the pull request.
  • Private by designToastty listens only on your Mac, and Tailscale Serve carries conversations over your own tailnet. No Toastty account is needed. Optional iPhone notifications in push-enabled builds send session titles and status through Cloudflare and Apple.

Available through TestFlight for now. Remote Access covers pairing and the tailnet setup.

Get started

Set up in a few minutes.

Download Toastty

Open the latest release and drag Toastty to Applications. Your Ghostty config carries over.

Paste the setup prompt

Copy it from Toastty ▸ Get Started with Toastty… and give it to any agent in a Toastty pane. It previews every change before writing anything.

Talk to the coordinator

Start it when Toastty asks, or from Agent ▸ Open Coordinator, and tell it what you need. ⌘⇧K brings back its chat on macOS 15 and later. From any other app, ⌥⇧T sends it a quick note. It turns both into tasks.

You are helping me set up Toastty. Please run: "$TOASTTY_CLI_PATH" setup guide Read the guide, narrate each step, dry-run every setup installer first (pass --dry-run), show me the planned writes, and wait for my explicit OK before rerunning anything with --apply.
Foundations

A real terminal underneath.

Ghostty renderingGPU-accelerated, and your existing Ghostty config just works.
Keyboard first⌘⇧P command palette, ⌘D to split, ⌥1–9 to switch workspaces. Full keyboard reference ↗
The coordinator, one key away⌘⇧K opens the coordinator's chat, on macOS 15 and later. ⌥⇧T sends it a note, or creates a task, from any app.
Terminal profilesOne-key launchers for tmux, herdr, SSH, or any startup command.
Layouts that persistWorkspaces, tabs, and splits come back after a restart, and with shell integration, so does each pane's history.
Local firstNo usage analytics or telemetry. Beyond update checks, Toastty only connects out for features you use, such as Remote Access or a diagnostics report you choose to send.
